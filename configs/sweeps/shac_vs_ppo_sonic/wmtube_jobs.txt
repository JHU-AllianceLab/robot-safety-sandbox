# The calibrated world-model tube (wmtube:<seconds>:<R>:<c>). Per SHAC seed:
#  1. calibration episodes (eval_sonic_qcbf.py condition wmcalib:16, --seed 1: 1024
#     kicked held-out episodes NOT in the evaluation lists): SONIC up to a random
#     decision step k ~ onset + U{0..50}; there 16 noisy world-model rollouts of
#     "u_SONIC, then SHAC" (3 s) are recorded; the real episode then does exactly
#     that (SONIC at k, SHAC from k+1) and its margins are recorded;
#  2. calibrate_wm_tube.py: eps_j at coverage 0.9 / 0.95 / 0.99 (conformal, per
#     step), coverage / tube volume / fall recall on a held-out half -> tube.json;
#  3. the filter on the evaluation episodes (--seed 0, the 512 of
#     wmrollout_noisy_eval_jobs.txt): SONIC while min over j <= H of (lowest predicted
#     margin_j - eps_j) >= 0, H = 0.4 / 1 / 3 s, next to the uncalibrated wmrollout:H:16.
# Sensor noise on, kick at the start. Under agentic_qos: one job, in turn.
python examples/eval_sonic_qcbf.py --policy runs/shac_vs_ppo_sonic/shac_s0/g1_recover_safetyshac1p/final_model.zip --tag shac_s0 --sonic-dir $HOME/gear_sonic_hf --hip mjlab --suites push --episodes 1024 --num-envs 256 --onset-s 0.02 0.02 --seed 1 --conditions sonic wmcalib:16 --out runs/shac_vs_ppo_sonic/wmtube_calib/shac_s0  # creates: runs/shac_vs_ppo_sonic/wmtube_calib/shac_s0/push.json
python examples/calibrate_wm_tube.py --calib runs/shac_vs_ppo_sonic/wmtube_calib/shac_s0/push.pt --tag shac_s0  # creates: runs/shac_vs_ppo_sonic/wmtube_calib/shac_s0/tube.json
