# Conformal tube on the WORST margin of one noise-free world-model rollout
# (wmmin:<seconds>:<c>), sensor noise OFF everywhere. Per SHAC seed:
#  1. calibration episodes (wmcalib:clean, --seed 1: 1024 kicked held-out episodes NOT in
#     the evaluation lists): SONIC up to a random decision step k ~ onset + U{0..50}, one
#     noise-free world-model rollout of "u_SONIC, then SHAC" (3 s), then exactly that in the
#     real env;
#  2. calibrate_wm_min_tube.py: eps_H(c) = conformal quantile of (predicted worst margin -
#     real worst margin) for H = 0.1 / 0.4 / 1 / 3 s and c = 0.9 / 0.95 / 0.99 -> min_tube.json;
#  3. the filter on the evaluation episodes (--seed 0, the 512 of
#     rollout_eval_startpush_noobsnoise_jobs.txt, CPU rollout filter there: 95-96 %): SONIC while
#     predicted worst margin over H - eps_H >= 0; next to wmrollout:H (eps = 0).
# Kick at the start. Under agentic_qos: one job, in turn.
