# Policy evaluation of the configs/sweeps/shac_vs_ppo_sonic fallbacks under
# g_fall, the BOOTSTRAPPED (TD) version, next to policy_eval_jobs.txt's exact
# rollout labels. Per final policy, one GPU, after its policy_eval_jobs.txt task
# (it reads the calib / test labels and the {v,q}_<tag>.pt fits for the comparison):
#   1. 50k random train_v states, one 3 s rollout each, EVERY state kept
#      (examples/record_policy_transitions.py; ~1.5 GB each, float16);
#   2. one step of every train_q (s, a) row (s' for Q's target);
#   3. 20k random calib states rolled out for 6 s, g only (the 3 s and the
#      6 s outcome of the same rollout);
#   4. examples/fit_policy_value_td.py: V by TD, bootstrapped along the rollouts
#      and at the 3 s truncation (a fall ends it at its g), with safety_sb3's
#      discounted backup V <- 0.01 g + 0.99 min(g, V') -- at gamma 1 the fixed
#      point is not unique and the fit collapses below g (smoke, 2026-10-28) --
#      then Q from it, the same thresholds on the same calib labels, and
#      compare_td_g099_<tag>.json (both fits against the exact 3 s labels).
# Outputs in data/policy_eval_gfall/: {v,q}_td_g099_<tag>.pt / .json, compare_td_g099_<tag>.json.
#   examples/run_jobs.sh configs/sweeps/shac_vs_ppo_sonic/policy_eval_td_jobs.txt --only $SLURM_ARRAY_TASK_ID   # array 1-6
python examples/record_policy_transitions.py --policy runs/shac_vs_ppo_sonic/shac_s0/g1_recover_safetyshac1p/final_model.zip --task g1_recover_lafan --states data/policy_eval_gfall/train_v.pt --rows 50000 --out data/policy_eval_gfall/td_train_v_traj_shac_s0.pt && python examples/record_policy_transitions.py --policy runs/shac_vs_ppo_sonic/shac_s0/g1_recover_safetyshac1p/final_model.zip --task g1_recover_lafan --states data/policy_eval_gfall/train_q.pt --mode q --horizon-s 0.02 --out data/policy_eval_gfall/td_train_q_step_shac_s0.pt && python examples/record_policy_transitions.py --policy runs/shac_vs_ppo_sonic/shac_s0/g1_recover_safetyshac1p/final_model.zip --task g1_recover_lafan --states data/policy_eval_gfall/calib_v.pt --rows 20000 --horizon-s 6 --no-features --out data/policy_eval_gfall/td_calib_v_h6_shac_s0.pt && python examples/fit_policy_value_td.py --dir data/policy_eval_gfall --tag shac_s0 --gamma 0.99 --variant td_g099  # creates: data/policy_eval_gfall/compare_td_g099_shac_s0.json
