# Dwell time instead of a latch: <cond>+dwell<s> = after each hand-over to SHAC, SHAC acts for at
# least <s> seconds; then the filter's verdict decides again (back to SONIC if it certifies
# u_SONIC, else SHAC stays until it does; the next hand-over starts a new dwell). Latch = an
# infinite dwell. Same 512 kicked held-out episodes per seed as wmlatch_jobs.txt / wmmin_jobs.txt
# (--seed 0 lists, kick at the start, sensor noise OFF), the same tube tables. Dwell 0.5 / 1 s
# on the WM tube filter (0.4 s at c = 0.95 and 0.9, 1 s at 0.95), the WM filter without a tube
# (wmrollout:1) and the exact CPU filter (rollout:1); 2 s on wmmin:0.4:0.95 toward the latch.
# shac_s0 re-renders the 9 episodes of wmlatch_eval/shac_s0/videos with panels SONIC | WM tube
# filter | dwell 0.5 s | dwell 1 s | latched. Run through wmdwell.sh (a smoke test first).
